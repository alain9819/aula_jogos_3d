Introdução

Apresentação do Projeto

Neste projeto, você aprenderá a desenvolver um ambiente 3D utilizando programação. Em vez de utilizar uma ferramenta visual pronta para criar jogos, você escreverá códigos que darão vida ao seu mundo virtual.

Você utilizará um modelo de personagem no formato .glb, aprenderá a posicioná-lo no cenário e programará seus movimentos usando o teclado.

O que você aprenderá?

  • Compreender a estrutura básica de um projeto Web.
  • Identificar as funções dos arquivos HTML, CSS e JavaScript.
  • Criar uma cena tridimensional com Three.js.
  • Trabalhar com coordenadas X, Y e Z.
  • Importar modelos 3D no formato .glb.
  • Criar iluminação, chão e objetos decorativos.
  • Programar a movimentação de um personagem.
  • Utilizar o teclado para controlar objetos.
  • Compreender como uma câmera acompanha o jogador.
  • Organizar e publicar um projeto utilizando GitHub.

Como será o resultado?

  1. Visualizar um campo aberto em 3D.
  2. Controlar um personagem com o teclado.
  3. Caminhar em diferentes direções.
  4. Observar a câmera acompanhando o personagem.
  5. Explorar um cenário com árvores e pedras.
Etapa 1

Preparando o ambiente de desenvolvimento

Antes de construir o jogo, precisamos organizar os arquivos e preparar o ambiente de trabalho.

Passo 1.1 — Criar a pasta do projeto

Abra o Visual Studio Code (VS Code). Com botão direito do mouse vão New File e crie index.html, style.css, game.js após isso vão em New Folder e crie a pasta assets, após isso faça o dowload do personagem.glb e arraste para assets.
Estrutura de arquivos:

Estrutura de Diretórios 
meu-mundo-3d/
│
├── index.html
├── style.css
├── game.js
│
└── assets/
    └── personagem.glb

Para que serve cada arquivo?

Arquivo / Pasta Função
index.htmlOrganiza os elementos da página e carrega o jogo.
style.cssDefine a aparência da página e da interface.
game.jsContém a programação do ambiente 3D e dos controles.
personagem.glbArmazena o modelo tridimensional do personagem.
assets/Guarda os modelos e outros recursos utilizados no jogo.

Etapa 4

Criando a primeira cena 3D com Three.js

Três elementos fundamentais são necessários para uma cena 3D:

  1. Cena: o espaço onde os objetos ficam.
  2. Câmera: de onde o jogador observa o mundo.
  3. Renderizador: desenha as imagens na tela.
game.js

// ==================================================
// 1. IMPORTAR O THREE.JS e DRACOLoader
// ==================================================

import * as THREE from 'three';

import { GLTFLoader } from
    'three/addons/loaders/GLTFLoader.js';

import { DRACOLoader } from
    'three/addons/loaders/DRACOLoader.js';
    
// ==================================================
// 2. ELEMENTOS DA PÁGINA
// ==================================================

const areaJogo = document.getElementById('jogo');

const mensagem = document.getElementById('mensagem');

const status = document.getElementById('status');


// ==================================================
// 3. CRIAR A CENA 3D
// ==================================================

const cena = new THREE.Scene();

// Cor do céu

cena.background = new THREE.Color(0x87ceeb);

// Neblina para dar profundidade ao cenário

cena.fog = new THREE.Fog(
    0x87ceeb,
    35,
    100

Etapa 10

Importando um personagem 3D com GLB

Fontes de modelos 3D gratuitos: Sketchfab, Poly Pizza e Khronos Sample Assets.

game.js 

// ==================================================
// 10. CRIAR O PERSONAGEM
// ==================================================


// Grupo que controla a posição e a direção do personagem


const personagem = new THREE.Group();


cena.add(personagem);



// Posição inicial


personagem.position.set(0, 0, 0);



// Variáveis do modelo


let modeloCarregado = false;


let mixer = null;



// Carregador de modelos comprimidos com Draco


const dracoLoader = new DRACOLoader();


dracoLoader.setDecoderPath(
    'https://cdn.jsdelivr.net/npm/three@0.180.0/examples/jsm/libs/draco/'
);


// Carregador de modelos 3D


const carregador = new GLTFLoader();


carregador.setDRACOLoader(dracoLoader);



// Importar o arquivo GLB


carregador.load(


    './assets/personagem.glb',
    


    function (gltf) {


        const modelo = gltf.scene;



        // Calcular o tamanho original do modelo


        const caixaInicial = new THREE.Box3()


            .setFromObject(modelo);



        const tamanhoInicial = new THREE.Vector3();


        caixaInicial.getSize(tamanhoInicial);



        // Ajustar a escala automaticamente


        const maiorDimensao = Math.max(


            tamanhoInicial.x,


            tamanhoInicial.y,


            tamanhoInicial.z


        );



        if (maiorDimensao > 0) {


            const escala = 1.8 / maiorDimensao;


            modelo.scale.setScalar(escala);


        }



        // Centralizar o modelo horizontalmente


        const centroInicial = new THREE.Box3()


            .setFromObject(modelo)


            .getCenter(new THREE.Vector3());



        modelo.position.x -= centroInicial.x;


        modelo.position.z -= centroInicial.z;



        // Ajustar os pés ao nível do chão


        const caixaFinal = new THREE.Box3()


            .setFromObject(modelo);



        modelo.position.y -= caixaFinal.min.y;



        // Configurar sombras


        modelo.traverse(function (objeto) {


            if (objeto.isMesh) {


                objeto.castShadow = true;


                objeto.receiveShadow = true;


            }


        });



        // Adicionar o modelo ao personagem


        personagem.add(modelo);



        // Preparar animações, caso o arquivo possua alguma


        if (gltf.animations.length > 0) {


            mixer = new THREE.AnimationMixer(modelo);


            const animacao = mixer.clipAction(


                gltf.animations[0]


            );


            animacao.play();


        }



        modeloCarregado = true;



        mensagem.style.display = 'none';


        status.textContent = 'Explore o campo!';



        console.log('Personagem carregado com sucesso!');


    },


    function (progresso) {


        if (progresso.total > 0) {


            const porcentagem = Math.round(


                progresso.loaded / progresso.total * 100


            );


            mensagem.textContent =


                `Carregando personagem: ${porcentagem}%`;


        }


    },


    undefined,


    function (erro) {


        console.error(


            'Erro ao carregar o personagem:',


            erro


        );


        mensagem.textContent =


            'Não foi possível carregar o personagem. ' +


            'Verifique o arquivo assets/personagem.glb.';


        status.textContent = 'Erro ao carregar o modelo';


    }


);

    const tecla = evento.key.toLowerCase();

});

    for (const tecla in teclas) {


        teclas[tecla] = false;

// ==================================================
// 15. FUNÇÃO PRINCIPAL DO JOGO
// ==================================================

function animar() {

    requestAnimationFrame(animar);


    // Calcular o tempo transcorrido

    const delta = Math.min(

        relogio.getDelta(),

        0.05

    );


    // Atualizar animações do modelo

    if (mixer) {

        mixer.update(delta);

    }


    // ==================================================
    // MOVIMENTAR O PERSONAGEM
    // ==================================================

    if (modeloCarregado) {

        // Zerar a direção antes de calcular o movimento

        direcao.set(0, 0, 0);


        // Movimentação horizontal

        if (

            teclas['w'] ||

            teclas['arrowup']

        ) {

            direcao.z -= 1;

        }


        if (

            teclas['s'] ||

            teclas['arrowdown']

        ) {

            direcao.z += 1;

        }


        // Movimentação lateral

        if (

            teclas['a'] ||

            teclas['arrowleft']

        ) {

            direcao.x -= 1;

        }


        if (

            teclas['d'] ||

            teclas['arrowright']

        ) {

            direcao.x += 1;

        }


        // Verificar se existe movimento

        if (direcao.lengthSq() > 0) {

            // Normalizar evita que a diagonal
            // seja mais rápida que o movimento reto

            direcao.normalize();


            // Movimentar o personagem

            personagem.position.x +=

                direcao.x * velocidade * delta;


            personagem.position.z +=

                direcao.z * velocidade * delta;


            // Girar o personagem na direção do movimento

            personagem.rotation.y = Math.atan2(

                direcao.x,

                direcao.z

            );

        }


        // Impedir que o personagem saia do campo

        personagem.position.x = THREE.MathUtils.clamp(

            personagem.position.x,

            -limiteCampo,

            limiteCampo

        );


        personagem.position.z = THREE.MathUtils.clamp(

            personagem.position.z,

            -limiteCampo,

            limiteCampo

        );


        // ==================================================
        // CÂMERA QUE ACOMPANHA O PERSONAGEM
        // ==================================================

        // Definir onde a câmera deve ficar

        const posicaoDesejada = new THREE.Vector3(

            personagem.position.x,

            personagem.position.y + 6,

            personagem.position.z + 9

        );


        // Movimento suave da câmera

        camera.position.lerp(

            posicaoDesejada,

            1 - Math.exp(-4 * delta)

        );


        // Definir o ponto que a câmera observa

        alvoCamera.set(

            personagem.position.x,

            personagem.position.y + 1,

            personagem.position.z

        );


        camera.lookAt(alvoCamera);

    }


    // ==================================================
    // DESENHAR A CENA
    // ==================================================

    renderer.render(

        cena,

        camera

    );

}

Etapa 19

Passo a passo para adicionar um colaborador no GitHub

  1. Acesse o repositório no GitHub , utilizando a conta do proprietário do projeto.
  2. Clique na aba Settings (Configurações), localizada no menu superior do repositório.
  3. Na barra lateral esquerda, clique em Collaborators (Colaboradores). O GitHub pode solicitar a confirmação da sua senha.
  4. Clique no botão verde Add people (Adicionar pessoas).
  5. Digite o nome de usuário do GitHub, o nome completo ou o e-mail do outro desenvolvedor e selecione a pessoa na lista.
  6. Clique em Add [nome de usuário] to this repository para enviar o convite.
  7. O outro desenvolvedor receberá um convite por e-mail e uma notificação no próprio GitHub. Ele precisará aceitar o convite para obter as permissões concedidas pelo proprietário, incluindo escrita no repositório, quando autorizada.

O que acontece depois?

Depois de aceitar o convite, o colaborador poderá participar do desenvolvimento do projeto conforme as permissões concedidas. Isso permite que os integrantes da equipe trabalhem no mesmo repositório, enviando alterações no código por meio de commit e push.

Etapa 21

Carregando novos modelos GLB

Após baixar o modelo 3D em formato GLB, siga os passos para carregá-lo

Insira os modelos GLB no diretório assets do seu projeto

game.js 
// ==================================================
// FUNÇÃO PARA CARREGAR MODELOS GLB
// ==================================================


function carregarModelo(
    arquivo,
    grupo,
    x,
    y,
    z,
    escala
) {


    // Carregar o arquivo GLB
    carregador.load(


        arquivo,


        // Quando o modelo terminar de carregar
        function (gltf) {


            const modelo = gltf.scene;


            // Definir a posição
            modelo.position.set(x, y, z);


            // Definir a escala
            modelo.scale.setScalar(escala);


            // Configurar sombras
            modelo.traverse(function (objeto) {


                if (objeto.isMesh) {


                    objeto.castShadow = true;


                    objeto.receiveShadow = true;


                }


            });


            // Adicionar o modelo ao grupo escolhido
            grupo.add(modelo);


            console.log(
                'Modelo carregado:',
                arquivo
            );


        },


        // Acompanhar o progresso do carregamento
        function (progresso) {


            if (progresso.total > 0) {


                const porcentagem = Math.round(
                    progresso.loaded /
                    progresso.total * 100
                );


                console.log(
                    `Carregando ${arquivo}: ${porcentagem}%`
                );


            }


        },


        // Tratar erros
        function (erro) {


            console.error(
                'Erro ao carregar:',
                arquivo,
                erro
            );


        }


    );


}

Criando Grupo de Modelos e Carregando Modelos

Na sequência do código anterior, vamos criar um grupo para armazenar os modelos carregados e desenvolver uma função para carregar os modelos GLB:

game.js 
// Grupo que organizará o cenário
const grupoCenario = new THREE.Group();


// Adicionar o grupo à cena
cena.add(grupoCenario);


// Carregar o cenário
carregarModelo(
    './assets/arbusto.glb',
    grupoCenario,
    0, 0, 0,
    1
);
